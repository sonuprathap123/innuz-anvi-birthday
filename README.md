# Innuz & Anvi — Birthday Website

## Preview
Extract this ZIP and open `index.html` in Chrome, Edge, or another browser.

## Included
- Responsive Malayalam-first birthday home page
- Innuz as the little host
- Interactive teeth quiz (correct answer: 6)
- Wish form preview (local browser only)
- Mobile-friendly layout

## Important
The wish form currently creates a preview on the device being used. It does not yet send or save wishes to a shared online location. Photo sharing and a shared gallery are placeholders. We can connect free Google Forms and a shared Google Photos album in the next step.

## Free publishing
This is a static website and can be hosted free using GitHub Pages. A free GitHub Pages URL can be used for the QR code; no paid domain is required.
